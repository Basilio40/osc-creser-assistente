# Frontend OSC Creser — Skills agrupadas + motor ChatGPT (site estático)

## Visão geral
Site 100% estático (HTML/CSS/JS puro, sem build, sem servidor) onde o usuário escolhe uma **skill agrupada por categoria de tarefa**, conversa com o motor GPT dentro do próprio frontend, e o comportamento fica limitado pelos **guardrails da OSC Creser** aplicados como system prompt em toda chamada.

## Arquivos a criar (em `GPT_CRESER/`)
```
GPT_CRESER/
├── index.html          # Layout: sidebar de skills + área de chat + modal de configurações
├── css/styles.css      # Visual limpo, identidade OSC Creser (ajustável)
├── js/
│   ├── guardrails.js   # Texto dos guardrails/instruções (PLACEHOLDER — você vai colar o texto real aqui; um único lugar fácil de editar)
│   ├── skills.js       # Definição das categorias e skills (nome, ícone, descrição, prompt-prefixo próprio da skill)
│   ├── api.js          # Chamada à API OpenAI (Chat Completions, com streaming), monta: guardrails + contexto da skill + histórico
│   └── app.js          # Estado, UI, localStorage (chave API, modelo, histórico)
└── README.md           # Como usar, editar skills/guardrails e onde colar a chave
```

## Como funciona
1. **Configuração (1ª vez):** usuário cola a chave da OpenAI num modal — salva apenas em `localStorage` do navegador, nunca sai do computador a não ser nas chamadas à API.
2. **Skills agrupadas:** sidebar com categorias (ex.: *Projetos, Captação de Recursos, Jurídico, Comunicação* — estrutura proposta, fácil de editar em `skills.js`). Cada skill injeta seu próprio prompt estruturado.
3. **Motor de resposta:** toda mensagem envia ao modelo:
   - `system`: guardrails OSC Creser + papel da skill ativa
   - histórico da conversa atual
   - mensagem do usuário
   - Modelo padrão `gpt-4o` (selecionável nas configurações).
4. **Guardrails garantidos:** o system prompt é sempre injetado pelo código (usuário não consegue "conversar a fora" dos limites), e o frontend não expõe edição dos guardrails em runtime — só via arquivo.

## Pendência sua
- Colar o texto real dos **guardrails/instruções** do seu GPT (vou deixar marcado com `<<< COLE AQUI >>>` em `js/guardrails.js`).
- Confirmar/ajustar as categorias de skills iniciais.

## Observação técnica
Não é possível usar exatamente "aquele GPT" pela URL — a API da OpenAI não dá acesso a um projeto/conversa específica do chatgpt.com. A solução replica o comportamento: mesmas instruções + skills, com o frontend como interface.
